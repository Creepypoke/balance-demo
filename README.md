# TriangleToss · треугольник равновесия

Лёгкая WebGL-игра для встраивания на HTML-страницу: подбросьте равносторонний треугольник с подписями «Время», «Стоимость», «Качество». Цель — приземлиться на вершину. Дизайн использует приложенный `triangle.jpeg` как ориентир; само изображение в сборку не входит.

**Без runtime-зависимостей, сетевых запросов, шрифтов и картинок.** Виджет содержит собственные стили и изолирован через Shadow DOM. Демостраница и её стили не входят в встраиваемый скрипт.

## Быстрый старт

Нужны Bun **1.4+** и pnpm **12.11+**.

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

Откройте адрес Vite из терминала, обычно `http://127.0.0.1:5173`. На демостранице есть настройка вероятности, выбор цвета и статистика.

```sh
pnpm test                 # тесты геометрии, физики и вероятности
pnpm run check            # TypeScript + Oxlint
pnpm run format           # Oxfmt
pnpm run build            # минифицированный встраиваемый виджет
pnpm run build:demo       # отдельный статический сайт → demo-dist/
pnpm run build:obfuscated # необязательная обфускация
```

### Артефакты

| Файл                                   | Назначение                                              |
| -------------------------------------- | ------------------------------------------------------- |
| `dist/triangle-toss.min.js`            | Минифицированный IIFE, глобальный объект `TriangleToss` |
| `dist/triangle-toss.es.js`             | Минифицированный ES-модуль с экспортом `create`         |
| `dist/triangle-toss.obfuscated.min.js` | IIFE после необязательной обфускации                    |
| `demo-dist/`                           | Демосайт, только после `build:demo`                     |

Размер обычного IIFE — примерно **19,3 KiB без сжатия / 8,1 KiB gzip**. Точный размер после сборки выводит `scripts/size.mjs`. Для доставки настройте gzip или Brotli на сервере. CSS и GLSL включены в JS; дополнительные ассеты не нужны.

Сборщик — **Vite 8 / Rolldown**, трансформация и минификация — **Oxc**, линтер — **Oxlint**, форматирование — **Oxfmt**. Lockfile фиксирует версии. Обфускатор — `javascript-obfuscator`; он только dev-зависимость. Обфускация увеличивает вес, не защищает клиентскую вероятность от подмены и потому выключена по умолчанию. Тяжёлые опции обфускации намеренно отключены.

## Встраивание

Скопируйте `dist/triangle-toss.min.js` на ваш сайт. Контейнеру нужна ширина хотя бы 180 px; рекомендуемая — 320–760 px. Высоту сцены виджет задаёт сам.

```html
<div id="triangle-game" style="max-width:640px"></div>
<script defer src="/assets/triangle-toss.min.js"></script>
<script defer src="/assets/init-triangle.js"></script>
```

Содержимое `init-triangle.js`:

```js
const game = TriangleToss.create("#triangle-game", {
  successRate: 0.3,
  counter: { initial: 0, visible: true, milestones: [5, 10, 25] },
  labels: ["Время", "Стоимость", "Качество"],
  style: {
    color: "#79d6a4",
    strokeColor: "#294c38",
    background: "#f6f8f3",
  },
  motion: { enabled: true, vibration: true },
  onSuccess: ({ count, source }) => console.log("Успех", count, source),
  onFailure: ({ count }) => console.log("Неудача", count),
  onCount: ({ count }) => console.log("Достигнут рубеж", count),
  onError: (error) => console.error(error),
});
```

Два `defer`-скрипта сохраняют порядок и не блокируют парсинг HTML. **Не используйте `async` для обоих**: порядок исполнения тогда не гарантирован. Полный пример есть в `examples/embed.html` и `examples/init.js`; положите копию артефакта рядом с ними и откройте через HTTP-сервер.

Для загрузки только когда виджет нужен:

```js
// В ES-модуле страницы; динамический import не блокирует парсинг HTML.
const { create } = await import("/assets/triangle-toss.es.js");
const game = create(document.getElementById("triangle-game"), { successRate: 0.5 });
```

Для SPA обязательно вызывайте `game.destroy()` при размонтировании. Инициализация добавляет отдельный узел в контейнер и не удаляет уже имеющееся содержимое.

## Настройки и API

Типы описаны в [`src/types.ts`](src/types.ts). В TypeScript-проекте можно импортировать `GameOptions`, `Game`, `ThrowResult` из исходников. Генерация отдельного `.d.ts` в эту сборку не включена.

| Настройка                 | По умолчанию                         | Поведение                                                                  |
| ------------------------- | ------------------------------------ | -------------------------------------------------------------------------- |
| `successRate`             | `0.3`                                | Конечное число 0…1; 0 — никогда, 1 — всегда                                |
| `counter.initial`         | `0`                                  | Начальный счётчик завершённых бросков, неотрицательное безопасное целое    |
| `counter.visible`         | `true`                               | Показывать счётчик в виджете                                               |
| `counter.milestones`      | `[]`                                 | Абсолютные значения счётчика для `onCount`, положительные безопасные целые |
| `labels`                  | `['Время', 'Стоимость', 'Качество']` | Левая, нижняя, правая сторона в начальном положении; текст, не HTML        |
| `style.color`             | `#79d6a4`                            | CSS-цвет заливки                                                           |
| `style.strokeColor`       | `#294c38`                            | CSS-цвет тонкого контура                                                   |
| `style.background`        | `#f6f8f3`                            | CSS-цвет фона                                                              |
| `style.fragmentShader`    | Встроенный градиент                  | Полный GLSL ES 1.00 fragment shader                                        |
| `motion.enabled`          | `true`                               | Показывать опцию тряски; **не** автоматически запрашивать доступ           |
| `motion.vibration`        | `true`                               | Разрешить необязательную вибрацию при включённой тряске                    |
| `onSuccess` / `onFailure` | —                                    | Ровно один callback после завершения принятого броска                      |
| `onCount`                 | —                                    | Callback на каждом достигнутом значении `milestones`                       |
| `onError`                 | Вывод в console                      | Ошибки шейдера, разрешений, пользовательских callbacks                     |

Длинные подписи обрезаются визуально, полный текст доступен через `title`. Для цветов используйте самостоятельные значения вроде HEX/RGB/HSL; `var(...)` и `currentColor` не наследуются в WebGL-заливку. Тема текста и элементов управления фиксирована светлой.

`ThrowResult`: `{ count, success, source }`, где `source` — `button`, `gesture`, `shake` или `api`. Сначала обновляются UI и счётчик, затем вызывается `onSuccess`/`onFailure`, затем `onCount`. Начальные рубежи не вызывают callback; изменение вероятности действует только на следующий бросок. Ошибка пользовательского callback не ломает игру.

```js
game.toss(); // true: принят; false: занят/невидим/слишком мал/удалён
game.setSuccessRate(1); // для следующих бросков
console.log(game.count); // только завершённые броски + counter.initial
await game.enableMotion(); // из click/tap; true означает API разрешён и слушатель включён
game.disableMotion();
console.log(game.motionEnabled);
game.destroy(); // идемпотентно: GPU-ресурсы, события, observers, DOM
```

Невалидные настройки, отсутствие контейнера, WebGL или ошибка компиляции шейдера выбрасывают исключение из `create()`. Обрабатывайте его на странице, показывая альтернативный текст. Для начальной ошибки WebGL/GLSL также вызывается `onError`. `destroy()` не завершает прерванный бросок и не вызывает callback результата.

### Как работает вероятность

`N` — **независимая вероятность каждой попытки**, а не квота на короткой серии. При `0.3` вполне возможны десять неудач подряд. Результат выбирается при старте через `Math.random() < N`, причём для 0 и 1 случайность не используется.

Треугольник поднимается и падает по баллистической траектории. На спуске вращение незаметно направляется к нужной ориентации **до первого касания пола**: на одну вершину при успехе или на грань при неудаче. План учитывает оставшееся время падения, сохраняет входящую угловую скорость и проверяет, что другая вершина не коснётся пола раньше. Длительность броска зависит от импульса, а не от фиксированного таймера.

При касании — короткое затухающее покачивание вокруг точки опоры (0,55 с). Треугольник не разворачивается из положения на грани в положение на вершине уже на полу и не возвращается искусственно к центру сцены. Вершина затем удерживается виртуально. **Это не чисто пассивная физическая система**: воздушная коррекция и удержание необходимы для гарантии заданной вероятности.

При `prefers-reduced-motion: reduce` бросок сразу переходит в финальное положение без анимации; счётчик и callbacks работают как обычно. Возможность получить результат от доступного управления сохраняется.

### Пользовательский шейдер

Шейдер компилируется один раз, не на каждом кадре. Интерфейс:

- `uniform vec4 u_color` — цвет настройки `style.color`;
- `uniform float u_time` — игровое время текущего броска в секундах;
- `varying vec2 v_local` — локальные координаты треугольника, радиус 1.

```js
style: {
  color: '#79d6a4',
  fragmentShader: `
    precision mediump float;
    uniform vec4 u_color;
    uniform float u_time;
    varying vec2 v_local;
    void main() {
      float bands = 0.9 + 0.1 * sin(v_local.y * 16.0 + u_time * 3.0);
      gl_FragColor = vec4(u_color.rgb * bands, u_color.a);
    }
  `,
}
```

Контур рисуется отдельно, подписи — DOM-элементы поверх WebGL. Собственный vertex shader и текстуры не предусмотрены. **В покое шейдер не анимируется**: это намеренное ограничение для экономии энергии. Не принимайте GLSL от недоверенных посетителей: сложный шейдер способен нагрузить GPU.

## Телефоны, датчики и вибрация

### Локальный HTTPS для iPhone

```sh
pnpm run dev:https
```

Команда создаёт локальный CA и сертификат для текущих LAN-адресов Mac, запускает игру на **5174/HTTPS** и отдельный сервер загрузки публичного CA на **5175/HTTP**. Нужен `openssl` в PATH. Дополнительные зависимости не требуются; обычный `pnpm run dev` остаётся HTTP. Адреса выводятся в терминале.

На iPhone, подключённом к той же Wi-Fi сети:

1. В Safari откройте `http://<IP-Mac>:5175/rootCA.cer`, разрешите загрузку профиля.
2. Откройте **Настройки → Основные → VPN и управление устройством** (или пункт «Профиль загружен») и установите `TriangleToss Local Development CA`.
3. Откройте **Настройки → Основные → Об этом устройстве → Доверие сертификатам** и включите полное доверие для этого CA.
4. Откройте `https://<IP-Mac>:5174/` без предупреждения о сертификате, затем нажмите «Тряска устройства» и разрешите датчики.

Сертификат устанавливайте только на собственное тестовое устройство в доверенной сети. Это настоящий корневой CA: после тестов удалите его профиль с iPhone. Для проверки отпечатка на Mac: `openssl x509 -in .local-cert/rootCA.pem -noout -fingerprint -sha256`.

Каталог `.local-cert/` исключён из Git и закрыт для выдачи через Vite; отдельный HTTP-сервер отдаёт только публичный DER-сертификат по `/rootCA.cer`. **Никогда не передавайте файлы `rootCA.key` и `server.key`.** Системное хранилище доверия Mac автоматически не меняется. Для проверки с Mac без установки CA используйте `curl --cacert .local-cert/rootCA.pem https://<IP-Mac>:5174/`.

CA действует 365 дней, серверный сертификат — 90 дней. Повторный запуск сохраняет CA и перевыпускает серверный сертификат, включая текущие IP. При смене сети перезапустите команду; при истечении CA потребуется заменить локальные сертификаты и заново установить доверие на iPhone. Проект не публикуется в интернете и не использует внешние туннели. Остановите сервер Ctrl+C после тестирования.

1. Откройте страницу по **HTTPS** (localhost допустим для локальной разработки).
2. Нажмите «Тряска устройства». На iOS вызывается `DeviceMotionEvent.requestPermission()` строго из пользовательского действия.
3. Встряхните телефон. Изменение `accelerationIncludingGravity` запускает бросок; горизонтальное ускорение и сила встряхивания влияют на начальный импульс. Датчики движения используются вместо постоянного опроса ориентации: для распознавания тряски именно ускорение полезнее гироскопа.

Порог изменения ускорения — 13 м/с², защита от повторов — 1,3 секунды; во время броска новый не принимается. Поддержка конструктора события не гарантирует наличие физических датчиков. `enableMotion()` сообщает о разрешении API, а не о доказанном наличии оборудования.

При включённой опции короткая вибрация соответствует заметным ударам о границы, успешное завершение — паттерну `[35, 60, 65]`. Удары ограничены по частоте. **Safari/iOS обычно не поддерживает Vibration API**; настольные браузеры могут предоставлять API без вибромотора. В этих случаях игра просто работает без вибрации. Обязательной гарантии тактильного отклика во всех браузерах нет.

В iframe родитель должен разрешить датчики, например `allow="accelerometer; gyroscope"`; серверные `Permissions-Policy` также не должны запрещать их. Нативное встраивание скрипта в страницу проще. Автоматические разрешения и обход пользовательского согласия не используются.

Кнопка, Enter/Space и тап по треугольнику работают без датчиков. Жест вверх поддерживается Pointer Events; прозрачная область захвата вокруг треугольника использует `touch-action: none`, чтобы свайп запускал бросок, а остальная сцена — `pan-y`, сохраняя прокрутку страницы. Начинайте жест на самом треугольнике; `pointercancel` безопасно отменяет незавершённый ввод.

## Производительность и эксплуатация

- Нет постоянного `requestAnimationFrame`: только во время броска, одно изображение в покое.
- Физика — фиксированный шаг 1/120 с; отрисовка — с частотой браузера. Дельта ограничена 50 мс, поэтому нет длинного догоняющего цикла после подвисания.
- Невидимая вкладка/контейнер приостанавливают бросок, возвращение продолжает его без скачка. Невидимые вызовы `toss()` не ставятся в очередь.
- WebGL 1, один треугольник и один контур, без depth buffer, DPR ограничен 1,75. GPU выбирается с `powerPreference: 'low-power'`.
- ResizeObserver реагирует на размер контейнера; потеря WebGL-контекста приостанавливает игру, восстановление пересоздаёт ресурсы.
- Можно создать несколько независимых экземпляров. Для большого числа виджетов загружайте только видимые: каждый экземпляр использует отдельный WebGL-контекст.
- Нет аналитики, cookies, backend, сохранения статистики или запросов к сторонним сервисам. Сохранять счётчик при необходимости должен хост.
- Shadow DOM изолирует CSS, но не является песочницей безопасности. Для строгого CSP/Trusted Types потребуется адаптировать вставку внутреннего HTML/стилей под политику сайта: текущий виджет использует `innerHTML`, встроенный `<style>` и inline style-свойства. Обфусцированный JS не использует `eval`.
- Для призов/денег клиентский результат непригоден: нужны серверная случайность, авторизация и проверка результатов. Эта реализация — визуальная маркетинговая мини-игра.

Подробности устройства — [`docs/architecture.md`](docs/architecture.md).
