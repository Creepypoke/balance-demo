КАК ВСТРОИТЬ

Два скрипта и контейнер

<div id="triangle-game" style="max-width:640px"></div>
<script defer src="/assets/triangle-toss.min.js"></script>
<script defer src="/assets/init-triangle.js"></script>
const game = TriangleToss.create("#triangle-game", {
  successRate: 0.35,
  confetti: true,
  counter: { initial: 0, visible: true, milestones: [5, 10, 25] },
  style: { color: "#79d6a4", strokeColor: "#294c38", background: "#f6f8f3" },
});

Параметры: successRate, labels (три подписи), style (цвет, обводка, фон), counter, confetti. Виджет не делает сетевых запросов и не загружает шрифтов.
